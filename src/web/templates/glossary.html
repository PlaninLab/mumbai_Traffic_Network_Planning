Glossary

Plain-language meanings for abbreviations, labels, and units used across the dashboard, corridor map, data page, and report.

← Dashboard Corridor map Collected data

Abbreviations

API
Application Programming Interface — the connection used to retrieve traffic data from a provider.
AM / PM
Before noon / after noon — the 12-hour clock labels used for collection windows in the report.
Avg
Average — the mean of a set of readings or values.
BMC
Brihanmumbai Municipal Corporation — the municipal area shown by the city map scope.
BPR
Bureau of Public Roads — the standard congestion curve used to estimate how travel time rises as a road fills.
EST.
Estimated — calculated from stated assumptions rather than directly measured.
HERE
The name of a traffic-data provider. It appears in capitals but is not an abbreviation.
HTTP
Hypertext Transfer Protocol — the web protocol used for requests to a data provider.
ID
Identifier — a unique reference used to trace a reading, junction, or provider request.
IST
Indian Standard Time — the local time zone used for collection windows, UTC+5:30.
JSON
JavaScript Object Notation — a structured text format used by the downloadable data endpoints.
M
Measured — read from live probe or provider data, not produced by the traffic model.
MMRDA
Mumbai Metropolitan Region Development Authority — the wider metropolitan map scope.
MOD
Modeled — calculated from demand, the road network, and the traffic-assignment model.
obs
Observations — individual traffic samples stored from collected readings.
OD
Origin–Destination — a trip or traffic flow from one locality to another.
OSM
OpenStreetMap — the open map source used for roads and intersections.
PCU
Passenger Car Unit — a common scale for mixed traffic. A car is 1 PCU; larger and smaller vehicles count proportionally.
SLO
Service-Level Objective — the provider reliability or response target used to classify an outage.
TSTT
Total System Travel Time — the combined travel time of every trip in the modeled network.
TTI
Travel Time Index — current travel time divided by free-flow travel time. 1.0 means no delay; 2.0 means twice as long.
UE
User Equilibrium — the modeled state where no driver can save time by changing routes.
UTC
Coordinated Universal Time — the common reference time used in system and provider records.
V/C
Volume-to-capacity ratio — traffic demand divided by road capacity. Above 1.0, vehicles arrive faster than the road can serve them.
WEH
Western Express Highway — the Dahisar-to-Bandra corridor modeled by this tool.

Symbols, labels, and units

Δ
Delta, meaning change from the baseline. For travel time, a negative value is an improvement and a positive value is worse.
Δ Corridor
Percentage change in total travel time on the selected corridor compared with the baseline.
Δ TSTT
Percentage change in Total System Travel Time across the whole modeled network compared with the baseline.
2D / 3D
Two-dimensional or three-dimensional map view.
cap
Capacity — the maximum traffic flow a road or approach can serve.
h / day
Hours per day — used for the number of peak-equivalent traffic hours in a day.
km
Kilometres — the unit used for corridor and queue length.
kph
Kilometres per hour — the unit used for vehicle speed.
m
Metres — the unit used for shorter queue lengths on the map.
min
Minutes — the unit used for trip duration.
PCU/h
Passenger Car Units per hour — the rate of traffic passing or arriving in one hour.
PCU-h
Passenger Car Unit-hours — a measure of combined vehicle time, such as congestion delay accumulated in one peak hour.
person-h
Person-hours — the combined time spent by all people, used when valuing congestion delay.
veh
Vehicles — a count of cars, buses, motorcycles, trucks, and other road traffic.
veh/km/lane
Vehicles per kilometre per lane — the density used to convert queued vehicles into a physical queue length.
yr
Year — used in annual congestion-cost assumptions.
Definitions reflect the labels currently used in the Mumbai Traffic Network Planning interface.
